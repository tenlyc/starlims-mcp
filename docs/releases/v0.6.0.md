# STARLIMS MCP 0.6.0

服务器侧 MCP 可以直接通过 SCM_API 执行，无需运行 DevTools。独立模式默认提供 14 个只读工具，允许写入后提供 29 个工具（含 get_capabilities）。与 DevTools 1.7.0 Beta 7 配套使用时提供 39 个工具。

- 补齐日志读取、签出列表与历史、对象和表维护、脚本/数据源执行、菜单查询/规划/创建；保留版本、签出状态及保存回读验证。
- 新增浏览器安全的 `@tenlyc/starlims-mcp/client` 入口。DevTools 通过该入口复用服务器执行层，继续管理登录会话、审批、质量门禁与桌面功能。原生多用户日志面板行为不变。
- 新增 `query_database` 和 `execute_database_change`，复用 STARLIMS Database 连接；修改必须逐次人工确认，默认只读模式不暴露修改或任意脚本执行。
- 预览、截图、DOM 检查、LSP、编辑器诊断和桌面输出这 10 个工具仍需要宿主。

安装配套 SCM_API.sdp 后使用数据库新接口。升级 MCP 服务不会自动部署 STARLIMS 后台脚本。

验证：41 项共享包测试、3 个 vendor 快照和生成文档校验通过；配套桌面 38 项 smoke tests、构建和 ESLint 基线通过。新桌面包真实登录后完成 39 工具握手、日志尾部读取、企业树/签出/历史/菜单/资源/表定义读取及数据库三项只读探针；中文测试页真实预览、DOM 检查及图片响应通过。

独立 stdio/HTTP 端到端测试使用服务器夹具；真实远端读取使用相同适配器经 DevTools HTTP 传输完成。未重新执行所有远端写操作，已有数据库逐次确认写入验收见 docs/DATABASE_ACCESS.md。Oracle、真实 Windows STARLIMS 运行和并发/断网提交仍未验收。预览存在四条既有 STARLIMS 系统控制台日志，页面加载成功。

See docs/STANDALONE.md for the complete capability matrix and connection setup. This release shares server execution with DevTools Beta 7; host-only preview/editor tools still require a desktop host. Database changes require per-call human approval and matching backend scripts.
